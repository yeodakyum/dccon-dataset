# Pilot 5 · 디시콘 320개 순위 비교

Pilot 2의 [320개 주석](../pilot2/results/annotations-320.jsonl), 기존 KOTE 감정 태그, [Terra 예문 9,600개](../pilot2/results/terra-examples-320.jsonl)를 사용합니다.

## 실행

원본 이미지가 있는 `data/week/`를 준비한 뒤 저장소 루트에서 실행하세요.

```bash
python -m pip install -r experiments/pilot3/requirements.txt
python experiments/pilot5/app.py
```

[통합 GUI](http://127.0.0.1:8772/)에서 Pilot 1~5를 전환할 수 있습니다. 기존 파일럿의 별도 실행 명령도 사용할 수 있습니다. 통합 GUI에서 Pilot 1~4는 처음 사용할 때 초기화됩니다. Pilot 1~3의 Ollama 기능에 다른 모델을 사용하려면 `--ollama-model`을 지정하세요. 기존 Groq 기능은 각 화면의 API 키 설정을 사용합니다.

Pilot 5는 로컬 KURE-v3 1,024차원 임베딩과 Pilot 3의 KOTE 분류기를 씁니다. 첫 입력 시 모델과 예문 임베딩을 준비합니다. 임베딩은 `data/pilot5/`에 저장해 다음 실행에서 재사용합니다. `--dataset`, `--cache`, `--port`로 경로와 포트를 지정할 수 있습니다.

## 비교

채팅 입력을 멈춘 뒤 250ms가 지나면 자동으로 점수를 계산합니다. 한글 조합이 끝난 입력을 사용합니다. 표에는 각 방식의 순위와 점수 및 전체 가중합 순위가 표시되며, 정렬 메뉴에서 보고 싶은 순서를 고를 수 있습니다. 어떤 컷오프를 적용해도 320개 콘을 모두 표시합니다.

| 항목 | 점수 | 기본 가중치 | 기본 컷오프 |
| --- | --- | --- | --- |
| 예문 | 컷오프 이상인 예문 코사인 유사도의 합 ÷ 사용한 예문 수 | 1.50 | 0.15 |
| 감정 | 입력의 KOTE 상위 3개 중 콘 태그와 일치하고 컷오프를 통과한 확률의 합 ÷ 3 | 0.35 | 0.50 |
| 이미지 문구 | 이미지 문구 중 최고 코사인 유사도 | 0.31 | 끔 |
| 반응 의도 | 반응 의도 중 최고 코사인 유사도 | 0.20 | 끔 |
| 시각 묘사 | 시각 묘사의 코사인 유사도 | 0.20 | 끔 |

가중합은 항목 점수에 가중치를 각각 곱해 더합니다. 가중치 슬라이더의 범위는 0~3입니다. 초기 정렬은 가중합이며, 가중 RRF는 꺼져 있습니다. 입력 감정 표시 컷오프의 기본값은 0.50입니다. 기준에 미달하거나 주석이 없는 항목의 점수는 0입니다. 가중치나 컷오프를 바꾸면 현재 계산 결과를 즉시 재정렬합니다. 예문 칸에는 통과 개수와 원래 합계도 표시합니다. 위 가중치는 비교를 시작하기 위한 초기값입니다.

**가중 RRF**를 켜면 항목별 순위를 기준으로 `가중치 / (60 + 순위)`를 더합니다. 항목 점수가 같은 콘은 같은 순위이고, 주석이 없거나 컷오프를 통과한 점수가 없는 항목은 합산에서 제외됩니다. 토글을 전환하면 같은 입력의 점수로 바로 다시 정렬합니다.

**예문 클러스터링**은 기본으로 꺼져 있으며 이때 콘당 예문 30개를 모두 사용합니다. 켜면 콘별로 코사인 거리 기반 완전 연결법(complete linkage)을 적용합니다. 코사인 유사도 0.80을 기준으로 묶고, 군집이 상한보다 많으면 상한에 도달할 때까지 더 합칩니다. 각 군집에서 다른 예문들과 평균 유사도가 가장 높은 예문을 대표로 사용합니다. **콘당 최대 예문 수**는 1~30개로 조절할 수 있고 초기값은 10개입니다. 예문 칸의 분수는 컷오프를 통과한 수와 실제 사용한 수를 표시합니다.

**군집 크기 가중치 (√크기)**는 클러스터링을 켠 상태에서 사용할 수 있으며 기본값은 꺼짐입니다. 켜면 컷오프를 통과한 대표 예문의 유사도에 각 군집 크기의 제곱근을 곱해 더한 뒤 전체 군집의 가중치 합으로 나눕니다. 같은 예문과 상한으로 즉시 순위를 비교할 수 있습니다.
