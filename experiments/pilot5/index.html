점수 계산 방식

텍스트 유사도는 KURE-v3 1,024차원 임베딩으로 계산합니다. 예문은 컷오프 이상인 코사인 유사도의 합을 사용한 예문 수로 나눕니다. 예문 클러스터링을 켜면 각 군집의 대표 예문을 사용합니다. 이미지 문구와 반응 의도는 각 항목의 최고 유사도, 시각 묘사는 유사도를 사용합니다. 감정은 입력의 KOTE 상위 3개 중 콘 태그와 일치하고 컷오프 이상인 확률을 합산한 뒤 3으로 나눕니다.

군집 크기 가중치를 켜면 컷오프를 통과한 대표 예문의 유사도에 군집 크기의 제곱근을 곱해 합산하고, 전체 대표 예문의 가중치 합으로 나눕니다.

가중합은 각 점수에 가중치를 곱해 더합니다. 누락되거나 컷오프를 통과하지 못한 점수는 0으로 계산합니다. 가중치 0은 해당 점수를 가중합에서 제외합니다. 컷오프 사용을 켜면 해당 기준을 적용합니다.

가중 RRF는 각 항목의 가중치를 (60 + 항목 순위)로 나눠 더합니다. 동점은 같은 순위로 계산하며, 컷오프를 통과한 점수가 없는 항목은 합산에서 제외됩니다.
