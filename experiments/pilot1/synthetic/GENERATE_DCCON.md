# 디시콘 합성 데이터 생성 프롬프트

이 파일을 Codex에 첨부하고 **“이 파일의 지시대로 실행해줘”**라고 요청하세요. 수량이나 경로를 함께 지정하면 해당 값을 적용합니다.

## 실행 지시

이 저장소에서 수집된 디시콘 100장을 직접 보고 한국어 합성 데이터를 작성하세요. 이미지 한 장을 열고 → 이미지에 근거해 태그와 사용 예시를 작성하고 → 해당 이미지의 JSON 한 파일을 저장하세요.

- 기본 입력은 `data/week/stickers.jsonl`입니다. `image_status == "ok"`인 행 중 로컬 원본을 열 수 있는 이미지를 고르세요. `image_path`는 `data/week/` 기준입니다. 가능하면 여러 패키지에서 골고루 선택하고, 동일한 SHA-256 이미지는 한 번만 처리하세요.
- 기본 출력은 `experiments/pilot1/synthetic/batch_100/<sticker_id>.json`입니다. 기존 결과가 있는 ID는 건너뛰고, 생성할 수량은 새로 저장한 파일 기준으로 세세요. 이전 파일을 다시 만들려면 요청에서 새 출력 폴더를 지정하거나 덮어쓰기를 명시하세요.
- **GPT-6.2 Sol 서브에이전트 3개**에 서로 겹치지 않는 이미지 목록을 나눠 주고, 메인도 별도 분량을 처리하세요. 에이전트마다 이 프롬프트와 할당 ID, 파일 경로를 전달하세요. 슬롯이 부족하면 남은 분량을 메인이 처리하세요.
- 이미지나 프레임을 모델이 직접 확인하세요. GIF는 가능하면 대표 프레임과 표정·문구·동작이 바뀌는 프레임을 함께 보세요. 정지 미리보기만 확인할 수 있으면 보이는 장면에 한해 작성하고 `image_view`에 그 사실을 기록하세요. 원본을 열 수 없으면 내용을 추정하지 말고 다른 이미지로 대체하세요.
- 이미지마다 UTF-8 JSON 객체 하나를 저장하세요. 목록을 한 파일로 합치거나 저장한 JSON을 대화에 재출력하지 마세요. 별도 검수·재채점·전수 재열람 단계는 생략하세요. 모든 작업이 끝나면 저장한 파일 수와 경로만 간단히 보고하세요.

## 이미지를 읽는 기준

1. **먼저 보이는 것을 적으세요.** `image_description`에 누가 무엇을 하는지와 핵심 시각 단서를 한두 문장으로 묘사하세요. 얼굴이 있으면 눈, 눈썹, 입, 시선, 눈물, 홍조처럼 실제 보이는 부분을 확인하세요. 종이나 캐릭터 이름이 불확실하면 ‘동물 캐릭터’처럼 확실한 범위로 표현하세요.
2. **시각 태그는 5개 정도 붙이세요.** 얼굴이 있으면 ‘반쯤 감긴 눈’, ‘한쪽 입꼬리를 올린 표정’, ‘눈을 크게 뜬 표정’처럼 구체적인 표정 태그를 최소 하나 넣으세요. 남은 태그는 자세·몸짓, 소품, 글자, 배경, 구도, 합성 효과 중 반응을 이해하는 데 도움이 되는 특징에 쓰세요. ‘눈’, ‘얼굴’, ‘캐릭터’처럼 범용적인 단어만 나열하지 마세요. 얼굴이 없는 이미지라면 글자 배치, 물체, 동작선, 대비 등 보이는 요소를 태깅하세요.
3. **이미지 속 문구를 보이는 대로 옮기세요.** `image_text` 배열에 읽히는 문구를 넣으세요. 글자가 없으면 빈 배열로 두고, 일부만 읽히면 그 부분만 적으세요. 문구가 잘렸거나 표기가 불명확하면 `interpretation_note`에 남기세요. 맞춤법이나 밈 특유의 오타를 임의로 고치지 마세요.
4. **문구의 뜻과 보내는 사람의 의도를 함께 보세요.** 예를 들어 “정말 알고 싶던 내용이에요”가 감사일 수도 있고, 반쯤 감긴 눈과 어깨를 으쓱하는 자세가 더해지면 엉뚱한 말을 받은 뒤의 빈정거림일 수도 있습니다. 어떤 해석이 맞는지는 앞선 대화가 결정합니다. 표정과 문구의 어긋남, 화제와 맞지 않는 답변, 과한 존댓말, 과장된 반응이 비꼼의 근거가 되는지 살피세요. 자기 실수를 놀리면 `자조`, 친한 상대를 가볍게 놀리면 `친근한 놀림`, 반대 뜻으로 칭찬하면 `반어`처럼 예시별 `usage_tags`에 의도를 구체적으로 적으세요. 애매한 이미지는 여러 해석이 가능하다고 기록하고, 근거가 약한 비꼼은 억지로 넣지 마세요.
5. **이미지와 대화가 왜 맞는지 한 문장으로 설명하세요.** `fit_reason`에는 앞 대화의 구체적 단서와 이미지에서 실제 보이는 단서를 하나씩 연결하세요. 예를 들어 “링크를 물었는데 키보드 얘기로 샌 직후라, 반쯤 감긴 눈과 과한 감사 문구가 빈정거리는 답으로 읽힌다.”처럼 쓰세요.

## 대화 작성 기준

- 이미지당 합성 사용 예시 5개를 작성하세요. 각 예시에 짧은 상황 설명, A/B의 이전 대화 2~5턴, 마지막 발화와 디시콘 전송을 넣으세요. 마지막 발화의 화자는 상황에 따라 A나 B가 될 수 있습니다.
- 비슷한 대화에서 소재만 바꾸는 대신, 이미지에 맞는 상황과 대화의 목적을 바꿔 보세요. 비꼼과 진심이 둘 다 자연스러운 이미지라면, 각각 왜 그렇게 읽히는지 드러나는 예시를 넣으세요. 용도가 뚜렷한 이미지라면 같은 의도를 서로 다른 관계나 상황에서 표현해도 됩니다.
- 메시지는 한국어 채팅처럼 짧게 쓰고, 인물 관계에 맞춰 반말과 존댓말을 사용하세요. 마지막 문장은 실제로 보낼 문장으로 쓰세요. 디시콘을 뜻하는 괄호나 설명은 문장에 넣지 말고 `send_sticker`로 표시하세요.
- `image_tags`에는 관찰 가능한 특징, `usage_tags`에는 해당 대화에서의 감정이나 목적을 넣으세요. 예를 들어 ‘눈물’은 시각 태그이고, 그 눈물을 써서 전하는 ‘자조’는 사용 태그입니다.
