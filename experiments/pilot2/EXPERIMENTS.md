# 파일럿 2 실험 기록

## 2026-11-23 · 혼합 데이터와 추천 방식

- 주간 랭킹의 100개 패키지에서 정지 이미지 160개와 GIF 160개를 추출했다. 첫 32개 주석을 재사용했다. Qwen 3.8 27B로 이미지 문구, 시각 묘사, 반응 의도와 근거, 불확실성을 기록했다. GIF는 재생 시간의 0·25·50·75·100% 프레임을 한 장으로 합쳤다.
- 기존 인덱스는 multilingual-e5-small과 FAISS를 사용한다. 이미지 문구, 반응 의도, 시각 묘사를 합쳐 임베딩하고, 같은 인덱스에서 원문 검색, Qwen 3.5 2B의 검색어 생성, 원문 상위 10개 중 Qwen 3.5 2B 선택을 비교했다. 후보 선택은 이미지 주석을 입력으로 받는다.
- 첫 8건에서 원문 검색은 위로 콘을 상위 10개에 넣지 못했다. SLM 검색어로는 안아주는 위로 콘이 3위에 나왔다. SLM 선택은 결승 진출과 파일 삭제라는 반대 문맥에 같은 웃는 GIF를 골랐고, 회의실 안내를 포함해 8건 모두에서 선택을 보류하지 않았다. 관찰된 중앙 응답 시간은 각각 0.1초, 4.5초, 8.3초였다.
- 검색어 출력을 짧은 반응 태그와 시각 묘사로 바꿨다. ‘위로·공감’을 예시로 제시한 초기 프롬프트는 해당 태그를 다른 상황에도 반복했다. 예시를 뺀 뒤 JSON 스키마를 적용하니 8건 모두 형식은 맞았으나 영문 태그와 화자 혼동이 남았다. 일정 안내에 태그를 생성했고, 후보 선택은 여전히 8건 모두에서 최소 1개를 골랐다. 이 결과는 합성 대화와 주석을 기준으로 본 소규모 점검이다.

### 유사 연구

- PEPE는 실제 트윗–GIF 답장 쌍에 고정 태그 예측과 대조학습을 적용했고, 실제 사용된 답장의 재현과 사람이 판단한 적합성을 따로 평가했다. [EMNLP 2021](https://aclanthology.org/2021.findings-emnlp.276/)
- Selecting Stickers는 대화와 후보 콘의 적합성을 이진 분류로 학습했다. [ACL 2022](https://aclanthology.org/2022.findings-acl.241/)
- IGSR은 관련 과거 대화와 현재 문맥에서 반응 의도를 추론하고, 대조학습한 검색 모델로 콘을 고른다. [AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/download/34720/36875)
- PerSRV는 사전 시각 주석과 OCR, 사용자 검색 상호작용을 활용해 후보 검색과 개인화 순위 결정을 수행한다. [WWW 2025](https://arxiv.org/abs/2410.21801)

## 2026-11-23 · 한국어 검색 임베딩 A/B

기존 `intfloat/multilingual-e5-small`과 이를 한국어 질의–문서 쌍으로 미세조정한 `dragonkue/multilingual-e5-small-ko`를 비교했다. 두 모델 모두 384차원이며, 같은 320개 주석, E5의 `query:`와 `passage:` 접두어, 정규화 및 FAISS 내적 검색을 사용했다. 공개 모델 설명에서 한국어 검색 튜닝은 확인되며, 디시콘이나 인터넷 은어 전용 학습은 확인되지 않았다. [한국어 모델 카드](https://huggingface.co/dragonkue/multilingual-e5-small-ko)

직전 8개 대화의 원문 8개와 당시 SLM 출력 8개를 고정했다. 추가로 놀람·놀림·무관심·기진맥진의 은어와 표준 표현 4쌍을 넣어 총 24개 검색어를 모델별로 검색했다. 검색어, 순위, 모델별 점수는 [A/B 결과 JSON](results/embedding-ab.json)에 있다. 원문과 고정 SLM 출력 16개는 모델 간 상위 10개가 평균 4.94개 겹쳤고, 은어·표준어 8개는 평균 4개 겹쳤다. 겹침은 순위 변화의 크기이며 적합도 점수가 아니다.

| 입력 | 기존 E5 | 한국어 E5 |
| --- | --- | --- |
| 와 이게 되네 ㄹㅇ? 개쩐다 | `ㄹㅇ입니까?` 1위, 웃는 `진짜야?` 2위 | 웃는 `진짜야?` 1위 |
| ㅇㅇ 알빠노 | 강한 부정 콘 1위, 조롱 콘 2위 | 감탄하는 `개쩌누` 1위 |
| 아 개빡세네 진짜 기빨림 | 상위 3개에 피로 태그가 없었음 | 상위 3개에 피로 태그가 없었음 |
| 정말 힘들어서 기운이 다 빠졌어 | `수고했어, 힘들겠다` 태그 콘 1위 | 같은 콘 1위 |
| 상실 위로의 원문 / 고정 SLM 출력 | 안아주는 위로 GIF가 두 입력 모두 상위 10개 밖 | 원문은 상위 10개 밖, 고정 SLM 출력은 9위 |

원문 대화 8건에서 한국어 E5는 `응... 그렇구나...`를 5건의 1위로 올렸다. 기존 E5도 다른 콘 하나를 5건의 1위로 올렸다. 한국어 모델로 검색 후보는 달라졌지만, 은어 해석이나 문맥별 추천이 일관되게 개선됐다는 근거는 관찰하지 못했다. 사례 평가는 OCR과 태그를 통한 정성 점검이며 사람 적합성 평가셋은 사용하지 않았다.

한국어 모델은 포트 8770에서 세 추천 방식을 실행해 확인했다. 포트 8767은 기존 E5 비교용이다.
